
The embedded software project is located under "mb1292b-controller" directory.

The directory structure of the project:
  - Drivers: The HAL/LL, BSP and CMSIS (copy pasted from GitHub)
  - Utilities: Librairies from GitHub or created for this project
  - main.c: entry point of the project
  - stm32wbxx_hal_msp.c: Initialisation of all the peripherals
  - stm32wbxx_it.c: Management of the interrupt
  - system_stm32wbxx.c: Boot of STM32
  - STM32CubeIDE: Project file
  - No STM32CubeMX file are present
